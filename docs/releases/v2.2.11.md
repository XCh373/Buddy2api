# Buddy2api v2.2.11

发布日期：2026-10-26

补丁版本：修复 WorkBuddy 桌面登录文件导入，兼容加密信封并避免异常凭据中断整批扫描。

## 账号导入

- 支持桌面客户端的 `$wbEncrypted` 加密信封，包括字典和 JSON 字符串格式，保留旧版明文登录文件兼容性。
- Windows 上从运行中的 WorkBuddy 客户端读取包装密钥，解包 keyblob 后使用主密钥解密字段。密钥仅缓存在内存中，使用前重新校验，客户端换钥后重新获取。
- 无法获取密钥、信封损坏或解密失败时跳过该文件，其他账号继续导入；失败文件不会覆盖已有账号的有效凭据。
- 检测结果展示解密失败原因，不再把无法解密的账号标为有效。

## 验证与适用范围

- 全量测试 498 项通过，覆盖异常文件混合扫描、字符串信封、密钥轮换、已有凭据保护及 AES-GCM 交叉验证。
- 真实 WorkBuddy 明文登录文件已验证首次导入、重复更新、凭据加密入库及聊天请求，返回 HTTP 200 / pong。
- 加密信封目前通过自动化测试验证，尚未完成新版加密客户端的真实联调。
- 加密登录文件导入需要 Windows 本机运行客户端并能读取其 keyblob。Linux / Docker 无法读取宿主机 Windows 客户端进程内存，请先在 Windows 本机导入，再按既有方式迁移加密数据库及配套凭据密钥。
- 如果导入成功后仍返回 401，请先确认官方客户端登录态有效；必要时重新登录后再次导入。
