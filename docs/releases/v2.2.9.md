# Buddy2api v2.2.9

发布日期：2026-10-26

小版本：一键更新沿用当前代理，设置页把 Loomy 上下文预算单独放出来，创建 Key 默认选自动通道。

## 一键更新

- 更新按钮仍执行 `git pull --ff-only`，不会写死代理端口，也不会改 Git 配置。
- 已有的 `HTTPS_PROXY`、`ALL_PROXY`、`HTTP_PROXY`，或 Git 自己的 `http.proxy`，继续优先使用。
- 都没有时，读取系统代理里的明确地址，只给这一次拉取和安装依赖使用。
- Windows 的绕过名单会一并带上。只配置了 PAC、没有具体地址时，Git 仍会直连。
- 连不上 GitHub 时，提示会说明这次有没有用到代理。

## 管理页

- Loomy 上下文预算从「自动化」卡片移到单独的「上下文预算」卡片。默认值、保存和 `0` 关闭裁剪都不变。
- 创建 Key 时默认选「自动通道」。已有 Key 不会被改通道。

## Docker

- 正式版发版成功后，同一个 workflow 会推送 `linux/amd64` 镜像到 `ghcr.io/wicm84266964/buddy2api:v2.2.9`，并移动 `latest`。

## 升级说明

- 不改数据库结构。
- 必须重启进程。正在运行的旧进程不会让更新按钮走代理。
- 管理页布局和创建 Key 的默认值在拉取新代码并刷新页面后生效。
- Docker 用户在镜像推送成功后，拉取 `v2.2.9` 再重启。源码部署继续 `docker compose up -d --build`。
