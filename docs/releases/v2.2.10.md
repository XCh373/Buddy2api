# Buddy2api v2.2.10

发布日期：2026-10-26

小版本：顶栏常驻检查更新和关闭按钮，创建 Key 时自动通道的说明不再被裁切。

## 管理页

- 右上角始终显示「检查更新」。点击会跳过 10 分钟缓存，重新核对远端版本。
- 有新版本时，旁边出现「更新到 vx.y.z」。已经是最新版本时不显示更新按钮。
- 右上角新增「关闭」。确认后正常停掉当前进程并释放端口。一键更新后没有黑色窗口时，用它关闭后台进程。
- 撤掉了只重新加载页面的刷新按钮。浏览器刷新仍然可用。
- 创建 Key 的窗口加宽，自动通道的说明会完整换行。列表里的通道框也能完整显示「自动通道」。

## 关闭

- 关闭按钮调用 `/admin/shutdown`，先返回结果，再退出进程。
- Docker 部署不走这个按钮。容器自动重启时，请在宿主机执行 `docker compose stop`。

## Docker

- 正式版发版成功后，同一个 workflow 会推送 `linux/amd64` 镜像到 `ghcr.io/wicm84266964/buddy2api:v2.2.10`，并移动 `latest`。

## 升级说明

- 不改数据库结构。
- 必须重启进程。正在运行的旧进程没有关闭按钮，也没有常驻的检查更新。
- 管理页布局在拉取新代码并刷新页面后生效。
- Docker 用户在镜像推送成功后，拉取 `v2.2.10` 再重启。源码部署继续 `docker compose up -d --build`。
