# Buddy2api v2.2.12

发布日期：2026-10-27

小版本：小浣熊增加新版客户端登录目录，并按用户标识分开保存已导入账号。

## 小浣熊

- 检测、重新检测和一键导入增加 `%USERPROFILE%\.office-raccoon\agent\config\auth.json`。
- 旧目录 `%USERPROFILE%\.box-agent\config\auth.json` 继续扫描。哪边有登录文件就导入哪边。
- `auth.json` 没有用户编号时，用登录 token 的用户标识区分账号。再导入另一个号不会覆盖已经导入的号。
- 同一台官方客户端仍然只保存当前登录。退出时如果上游作废旧登录，已保存的号仍会失效。

## 升级说明

- 不改数据库结构。
- 必须重启进程。旧进程不会扫描新目录。
- 正式版发版成功后推送 `ghcr.io/wicm84266964/buddy2api:v2.2.12`（`linux/amd64`），并移动 `latest`。

感谢 @dyed-fanxing 在 [#125](https://github.com/wicm84266964/Buddy2api/issues/125) 反馈新版登录目录。
