# Buddy2api v2.2.8

发布日期：2026-10-25

小版本：小浣熊失败请求写入日志，流式成功请求按最后的 usage 统计 token。

## 小浣熊

- 非流式和流式失败都会进入请求日志，带上状态码和上游原文（最多 400 字）。
- 中间重试记为 `retry`，不增加账号和 Key 次数。
- 最终失败记为 `error`，保留真实状态码、账号和上游原文，并计入用量。
- 网络错误和鉴权错误记 503。重试耗尽时不再只留在控制台。
- 流式成功请求从最后一个 usage chunk 读取 prompt、completion 和 total token。没有 usage 时仍记 0。
- `finish_reason` 以流里最后出现的值为准；没有时仍是 `stop`。

## Docker

- 正式版发版成功后，同一个 workflow 会推送 `linux/amd64` 镜像到 `ghcr.io/wicm84266964/buddy2api:v2.2.8`，并移动 `latest`。

## 升级说明

- 不改数据库结构。
- 必须重启进程。正在运行的旧进程不会补记小浣熊失败，也不会读取流式 usage。
- Docker 用户在镜像推送成功后，拉取 `v2.2.8` 再重启。源码部署继续 `docker compose up -d --build`。
